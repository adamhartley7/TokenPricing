LLM Token Cost Calculator

Estimate monthly USD for DeepSeek, Claude API, and Gemini at your own token volumes — with Claude Max flat plans shown as reference lines. Neutral by design: see the cost winner and the caveats side by side.

Read this first. DeepSeek is consistently the cheapest metered option here, often by 10×–35× versus frontier Claude/Gemini tiers. The trade-offs are real and separate from price: DeepSeek's hosted API stores data on servers in the People's Republic of China and is subject to PRC law (multiple governments restrict it on official devices); and DeepSeek V4 Pro Max scores ~80.6% on SWE-bench Verified vs Opus 4.8 at ~88.6%. Self-hosting DeepSeek's open-weight (MIT) models or using a Western host avoids the China data path. Pick on cost and jurisdiction and quality — this tool only computes cost. Several DeepSeek/Gemini figures below are from search-snippet fallbacks, not the official pages (the official pages returned HTTP 403 this run) — verify live before relying on them.

Claude Max is a flat, interactive-only plan — not an API tier. Pro $20 / Max 5× $100 / Max 20× $200 per month buy rate-limited interactive access (roughly ~225 messages per rolling 5h on 5×, ~900 on 20×; the 5-hour limit was doubled on 6 May 2026). Anthropic does not publish exact token quotas for these plans, so this tool does not invent any — the $100/$200 lines are the flat prices, shown only as reference markers. Change (15 Jun 2026): programmatic / non-interactive usage (Agent SDK, claude -p, GitHub Actions, scheduled/headless runs) draws from a separate monthly credit pool billed at API rates — $20 (Pro) / $100 (Max 5×) / $200 (Max 20×). Interactive terminal use is unaffected. If you run parallel agentic loops headlessly, you are effectively on metered API pricing, not the flat plan.

Neutrality & accuracy. This calculator favours no vendor. DeepSeek cost note: V4 Pro is shown at $0.435/$0.87 — the original $1.74/$3.48 list price minus the 75% reduction that, per multiple corroborating sources, became permanent after 2026-05-31 (DeepSeek's own page returned HTTP 403, so this is corroborated across aggregators rather than read off the official page). V4 Flash cache-hit input is ~$0.0028/1M (a ~98% discount), steeper than the uniform ~90% cache credit this tool applies — so raising the cache slider under-credits DeepSeek slightly. Legacy deepseek-chat / deepseek-reasoner deprecate 2026-07-24 and route to V4 Flash.

Two modelling simplifications: (1) cache-read is treated as a uniform 0.1× of input for every option, whereas DeepSeek's is steeper (~0.02×); (2) Gemini 3 Pro's price doubles to $4/$18 above 200K-token prompts — this tool uses the ≤200K rate, so very large-context Gemini Pro runs cost more than shown.

Route Claude Code → DeepSeek (Windows PowerShell)

Official Anthropic-compatible endpoint. Be aware tool-use reliability with non-Anthropic models can differ from native Claude — test your agentic loops.

$env:ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
$env:ANTHROPIC_AUTH_TOKEN="<your-deepseek-key>"
$env:ANTHROPIC_MODEL="deepseek-v4-pro"
$env:ANTHROPIC_DEFAULT_OPUS_MODEL="deepseek-v4-pro"
$env:ANTHROPIC_DEFAULT_SONNET_MODEL="deepseek-v4-pro"
$env:ANTHROPIC_DEFAULT_HAIKU_MODEL="deepseek-v4-flash"
$env:CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC="1"
$env:CLAUDE_CODE_EFFORT_LEVEL="max"

Community alternative: @musistudio/claude-code-router (a third-party, not Anthropic, multi-provider proxy): npm i -g @musistudio/claude-code-router then ccr code. Config lives in ~/.claude-code-router/config.json; some transformers are experimental. Restart with ccr restart after config changes.
